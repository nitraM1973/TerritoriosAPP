**Territory App** es una solución desarrollada para simplificar la organización, asignación y seguimiento de territorios. Diseñada para ser intuitiva, rápida y estar siempre actualizada.

## 🚀 Instalación Rápida

¿Es tu primera vez instalando la aplicación? Sigue estos sencillos pasos:

1.  **Descarga**: Pulsa el botón de abajo para bajar el archivo instalador (APK).
2.  **Abre el archivo**: Una vez descargado, tócalo en tu barra de notificaciones o carpeta de descargas.
3.  **Permisos**: Si Android te advierte sobre "Fuentes desconocidas", pulsa en **Ajustes** y activa la opción **"Permitir desde esta fuente"**.
4.  **¡Listo!**: Dale a "Instalar" y ya puedes empezar.

> [!TIP]
> **Actualizaciones automáticas**: No hace falta que vuelvas aquí a descargar. La propia aplicación te avisará cuando haya una nueva mejora disponible y se actualizará sola.

## ✨ Características Principales

*   **🔑 Acceso Seguro**: Registro con nicknames únicos y validación en tiempo real.
*   **📡 Sincronización Real**: Datos en la nube para que todos los usuarios vean los cambios al instante.
*   **📂 Gestión de Territorios**: Listados detallados, mapas de estado y filtros avanzados.
*   **🔔 Notificaciones**: Recibe avisos importantes directamente en tu móvil.
*   **🖐️ Biometría**: Acceso ultrarrápido con huella dactilar o reconocimiento facial.

## 🛠️ Tecnologías Utilizadas

*   **.NET MAUI 10.0** (Cross-platform framework)
*   **Firebase** (Real-time Database & Auth)
*   **CommunityToolkit.Mvvm** (Arquitectura limpia)
*   **GitHub Releases** (Sistema de distribución y OTA updates)
